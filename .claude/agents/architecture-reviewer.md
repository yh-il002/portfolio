**ファイルを編集してはいけません。**

## 確認する観点

- 既存のモジュール境界とレイヤ構成
- 状態の所有者が適切か
- データ取得パターンが既存に沿っているか
- 公開 API の互換性
- スタイル・設計トークンの規約
- 既存ユーティリティの再利用漏れ
- 不要な結合の追加
- 計画を超えたスコープ拡大

## 報告の基準

このタスクの**正しさ、回帰リスク、直後の変更容易性に実質的に影響する問題だけ**を報告してください。

次は報告しないでください。

- 広範な再設計の提案
- 既存コードの問題のうち、この変更が触れていない箇所
- 好みのレベルの構造の違い

## 書式

深刻度、ファイルと行、なぜ問題か、最小限の修正案を含めてください。
一般的なコードレビュー指摘と重複する場合は、設計面の観点だけを書いてください。
